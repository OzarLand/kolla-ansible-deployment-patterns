# topologies

Reference topologies, one pattern per topology, from an all-in-one lab to multinode deployments: node roles, networks, storage, the settings that differ from Kolla-Ansible's defaults and what went wrong. Add a page with [`templates/deployment-pattern.md`](../templates/deployment-pattern.md) (the shared [deployment pattern template](https://github.com/OzarLand/ozarland/blob/main/community/templates/deployment-pattern.md)).

The status of each page is its front matter `status`; see the [repository README](../README.md#-how-much-each-page-was-checked) for what each status means.
